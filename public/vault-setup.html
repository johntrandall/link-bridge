Open in Obsidian

Opens the Obsidian vault at this folder's git repository root, creating the vault first if there is none. If nothing happened, press the button. The first time, Chrome asks whether this site may open "Open in Obsidian"; tick Always allow to skip that question next time. This needs the obsidian-vault-setup handler app installed on this Mac; it accepts only an existing folder under your home folder.
